# 画面設計

- 作成日: 2026-10-08
- 前提: [requirements.md](requirements.md)(機能・URL)、[design-guide.md](design-guide.md)(見た目のルール)

ワイヤーフレームは配置を示すための簡易図で、細かい見た目はデザインガイドに従う。

## 1. 全体レイアウト

### 1.1 PC(幅 1024px 以上)

```
┌──────────────┬──────────────────────────────────────────┐
│ Quiz         │  カテゴリ › 基本情報 › ネットワーク      │ ← パンくず
│              │                                          │
│ カテゴリ   + │  ネットワーク                 [ … ]      │ ← ページ見出し+メニュー
│ ▾ 基本情報   │  ─────────────────────────────           │
│   ・ネット.. │                                          │
│   ・DB       │        (メイン領域 max-w-3xl)            │
│ ▸ 英語       │                                          │
│ ▸ Laravel    │                                          │
│              │                                          │
│              │                                          │
│ ──────────── │                                          │
│ ログアウト   │                                          │
└──────────────┴──────────────────────────────────────────┘
  幅 256px 固定        残りの幅。中身は中央寄せ
```

- サイドバーは白背景・右端に `zinc-200` の罫線。画面に固定し、メイン領域だけスクロールする
- サイドバーにはカテゴリの一覧を出し、各カテゴリを開くと中のセクションが表示される
  - 現在のページが属するカテゴリは最初から開いておく
  - 現在地のセクションは `brand-50` 背景 + `brand-600` 文字
- 「カテゴリ」見出しの横の「+」でカテゴリ作成画面へ移動する
- 一番下にログアウトボタン

### 1.2 スマホ(幅 1024px 未満)

```
┌──────────────────────────────┐
│ ☰  Quiz                      │ ← ヘッダー(画面上部に固定)
├──────────────────────────────┤
│ … › ネットワーク             │ ← パンくず(途中省略)
│                              │
│ ネットワーク          [ … ]  │
│                              │
│ (メイン領域 px-4)          │
│                              │
└──────────────────────────────┘
```

- ☰ を押すと、PC と同じサイドバーが左からドロワーとして出てくる
- ドロワーは、背景のタップ・リンクの選択・Esc キーで閉じる

### 1.3 ページの共通構成

すべてのページは上から次の順に並べる。

1. パンくず
2. ページ見出し(右側に主ボタンか「…」メニュー)
3. 補足情報(件数や日時。あれば)
4. 本文

## 2. 画面ごとの設計

### 2.1 ログイン `/login`

```
┌──────────────────────────────┐
│                              │
│            Quiz              │
│   AIが採点する学習ノート     │
│                              │
│   ┌──────────────────────┐   │
│   │ メールアドレス       │   │
│   │ [                  ] │   │
│   │ パスワード           │   │
│   │ [                  ] │   │
│   │ [x] ログイン状態を保持│   │
│   │ [     ログイン     ] │   │
│   └──────────────────────┘   │
└──────────────────────────────┘
```

- サイドバーなしのレイアウト。カードを画面中央に置く
- 認証エラーはフォームの上に1つだけ表示する(どちらの項目が違うかは出さない)
- ログイン試行回数の制限に達したら、何秒後に再試行できるかを表示する

### 2.2 カテゴリ一覧 `/categories`(ログイン後の着地点)

```
カテゴリ                                 [+ カテゴリを作成]

┌─────────────────────┐ ┌─────────────────────┐
│ 基本情報            │ │ 英語                │
│ 3セクション・24問   │ │ 1セクション・8問    │
│ 最終挑戦 10/7       │ │ 最終挑戦 9/30       │
└─────────────────────┘ └─────────────────────┘
┌─────────────────────┐
│ Laravel             │
│ 2セクション・15問   │
│ まだ挑戦していません│
└─────────────────────┘
```

- PC は2列、スマホは1列のカード
- カード全体がカテゴリ詳細へのリンク
- 0件のときは空の状態(「最初のカテゴリを作りましょう」+「カテゴリを作成」)
- 並び順は作成順

### 2.3 カテゴリ作成・編集 `/categories/create`、`/categories/{category}/edit`

```
カテゴリ › 新規作成

カテゴリを作成

  カテゴリ名
  [                              ]

                    [キャンセル] [作成する]
```

- 作成と編集で同じフォーム部品を使う(ボタンの文言だけ「作成する」/「保存する」に変える)
- 保存すると詳細画面へ移動し、トースト「カテゴリを作成しました」を表示する

### 2.4 カテゴリ詳細 `/categories/{category}`

```
カテゴリ › 基本情報

基本情報                                [ … ]  ← 編集 / 削除
3セクション

セクション                          [+ セクションを追加]
┌─────────────────────────────────────────────────────┐
│ ネットワーク          8問   平均 72   最終 10/7  › │
├─────────────────────────────────────────────────────┤
│ データベース          10問  平均 58   最終 10/1  › │
├─────────────────────────────────────────────────────┤
│ セキュリティ          6問   —         未挑戦     › │
└─────────────────────────────────────────────────────┘
```

- セクションは1枚のカードの中に行として並べる(各行がセクション詳細へのリンク)
- 「平均」は直近の挑戦の平均点。点数バッジの色分けで表示する
- スマホでは「最終」を2行目に回す
- 削除の確認モーダルには「セクション3件、問題24件、履歴〇件も削除されます」と表示する

### 2.5 セクション作成・編集

- 作成: セクション名のみ入力(カテゴリは URL で決まっている)
- 編集: セクション名のみ(所属カテゴリは変更できない)
- 見た目は 2.3 と同じ

### 2.6 セクション詳細 `/sections/{section}`(よく使う画面)

```
カテゴリ › 基本情報 › ネットワーク

ネットワーク                               [ … ]  ← 編集 / 削除
8 / 10問・最終挑戦 10/7

┌─────────────────────────────────────────────────────┐
│ [ 全問に回答する(8問) ]   [ 苦手だけ再挑戦(2問) ]  │
│                              [ 履歴を見る ]         │
└─────────────────────────────────────────────────────┘

問題                                      [+ 問題を追加]
┌─────────────────────────────────────────────────────┐
│ 1  TCPとUDPの違いを説明して…          [ 82 ]   … │
├─────────────────────────────────────────────────────┤
│ 2  DNSの名前解決の流れを…             [ 45 ]   … │
├─────────────────────────────────────────────────────┤
│ 3  HTTPSで通信が暗号化される…         [ —  ]   … │
└─────────────────────────────────────────────────────┘
```

- 上部の操作エリア
  - 「全問に回答する」が主ボタン(primary)
  - 「苦手だけ再挑戦」は副ボタン(secondary)。苦手問題が0問のときは無効にし、「苦手な問題はありません」と添える
  - 「履歴を見る」は ghost ボタン
- 問題の各行
  - 本文の先頭40文字と、最新の点数バッジを表示する
  - 行を押すと問題詳細へ移動する。「…」から編集・削除
- 問題が10問に達したら「+ 問題を追加」を無効にし、「上限の10問に達しています」と表示する
- 問題が0問のときは操作エリアを出さず、空の状態を表示する

### 2.7 問題作成・編集 `/sections/{section}/questions/create`、`/questions/{question}/edit`

```
… › ネットワーク › 問題を追加

問題を追加

  問題文
  ┌──────────────────────────────────────┐
  │                                      │
  │                                      │
  └──────────────────────────────────────┘
                                 0 / 2000

                 [キャンセル] [追加する]
```

- 編集も問題文だけ(所属セクションは変更できない)
- 作成後はセクション詳細に戻る(続けて追加しやすいように)

### 2.8 問題詳細 `/questions/{question}`

```
… › ネットワーク › 問題 2

問題 2                                      [ … ]  ← 編集 / 削除

┌─────────────────────────────────────────────────────┐
│ DNSの名前解決の流れを説明してください。             │
└─────────────────────────────────────────────────────┘

最近の点数
  10/7  [ 45 ]  厳しい
  10/1  [ 52 ]  普通
  9/28  [ 38 ]  普通
```

- 「最近の点数」は直近5件。各行から、その回の履歴詳細へ移動できる

### 2.9 回答フォーム `/sections/{section}/answers/create?mode=all|weak`

```
… › ネットワーク › 回答

全問に回答する                        3 / 8 問 回答済み
                                     ✓ 下書きを保存しました

採点レベル
┌──────────┬──────────┬──────────┐
│  優しい  │ ◉ 普通   │  厳しい  │
└──────────┴──────────┴──────────┘

┌─────────────────────────────────────────────────────┐
│ 問題 1                                     ✓ 回答済 │
│ TCPとUDPの違いを説明してください。                  │
│ ┌─────────────────────────────────────────────────┐ │
│ │ TCPはコネクション型で…                          │ │
│ └─────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────┐
│ 問題 2                                              │
│ …                                                   │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│               [ 採点する(8問) ]                    │ ← スマホでは画面下に固定
└─────────────────────────────────────────────────────┘
```

- 苦手モードのときは見出しを「苦手な問題に再挑戦」にし、「前回60点未満だった2問です」と添える
- 進捗表示: 入力済みの問題数を数えて表示する。入力済みの問題カードには「✓ 回答済」を付ける
- 下書き
  - 入力が止まって1秒後に localStorage へ保存し、「✓ 下書きを保存しました」を数秒表示する
  - ページを開いたときに下書きがあれば復元し、トースト「前回の下書きを復元しました」を表示する
  - 下書きを捨てたい場合のために、「下書きを破棄」(ghost)を進捗表示の近くに置く
- 送信
  - 未入力の問題があると送信できない。最初の未入力欄へスクロールし、エラーを表示する
  - 送信中はボタンを無効にし、「送信中…」と表示する
- 入力途中でページを離れようとしたら、ブラウザの離脱確認を出す。下書きはあるが念のため

### 2.10 採点結果・履歴詳細 `/sections/{section}/history/{attempt}`

1つの画面で、採点の状態に応じて表示を切り替える。

#### (a) 採点中(`pending` / `grading`)

```
… › ネットワーク › 履歴 › 10/8 14:32

採点しています…
AIが8問の回答を確認しています。1分ほどかかることがあります。
このページを離れても採点は続きます。

┌─────────────────────────────────────────────────────┐
│ ▒▒▒▒▒▒▒▒▒▒                               ▒▒▒▒      │ ← スケルトン
│ ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒                            │
└─────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────┐
│ ▒▒▒▒▒▒▒▒▒▒                               ▒▒▒▒      │
└─────────────────────────────────────────────────────┘
```

- 3秒ごとに `/attempts/{attempt}/status` を確認する。`completed` か `failed` になったらページを再読み込みする
- 確認が5分続いても終わらない場合は止めて、「時間がかかっています。しばらくしてから再読み込みしてください」と表示する

#### (b) 採点完了(`completed`)

```
… › ネットワーク › 履歴 › 10/8 14:32

採点結果                                    [ 全問 ] [ 普通 ]
10月8日 14:32

┌─────────────────────────────────────────────────────┐
│   平均点                                            │
│   72  ▲6                         8問中 80点以上 3問 │
│                                       60点未満 2問 │
└─────────────────────────────────────────────────────┘

[ もう一度挑戦する ]  [ 苦手だけ再挑戦(2問) ]

┌─────────────────────────────────────────────────────┐
│ 問題 1                           [ 82 ] ▲12     ▾ │
├─────────────────────────────────────────────────────┤
│ TCPとUDPの違いを説明してください。                  │
│                                                     │
│ あなたの回答                                        │
│ ┊ TCPはコネクション型で…                            │
│                                                     │
│ 良い点                                              │
│ 信頼性の違いに触れられています。…                   │
│ 改善点                                              │
│ 用途の具体例があるとよりよいです。…                 │
│ 改善例                                              │
│ ┊ TCPは…、UDPは動画配信など…                        │
└─────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────┐
│ 問題 2                           [ 45 ] ▼7      ▸ │ ← 閉じた状態
└─────────────────────────────────────────────────────┘

使用量: 入力 12,340 / 出力 3,210 トークン・検索 2回・約 $0.08
```

- 平均点のカード
  - 平均点を大きく表示し、同じ種別(全問 / 苦手)の前回の挑戦との差を添える
  - 右側に点数帯ごとの問題数
- 問題ごとのカード
  - 初期状態は **60点未満の問題だけ開いておく**(見直すべきものに目が行くように)
  - 見出し行を押すと開閉する
  - 前回比は、その問題の前回の点数との差
- 「あなたの回答」と「改善例」は、左に `zinc-200` の縦線を付けた引用の見た目にする
- 使用量は画面の一番下に `text-xs text-zinc-500` で控えめに表示する

#### (c) 採点失敗(`failed`)

```
採点できませんでした
AIの採点中にエラーが発生しました。回答は保存されているので、
入力し直さずに再採点できます。

[ 再採点する ]   [ セクションに戻る ]

あなたの回答(8問)
┌─────────────────────────────────────────────────────┐
│ 問題 1  TCPとUDPの違いを…                         ▸ │
└─────────────────────────────────────────────────────┘
```

- 「再採点する」は `POST /attempts/{attempt}/regrade`。押すと (a) の採点中の表示に戻る
- 失敗の詳しい理由は画面に出さない(ログで確認する)

### 2.11 履歴一覧 `/sections/{section}/history`

```
… › ネットワーク › 履歴

履歴                                              12件

┌─────────────────────────────────────────────────────┐
│ 10/8 14:32  [全問] 普通  8問          [ 72 ]    › │
├─────────────────────────────────────────────────────┤
│ 10/7 21:05  [苦手] 厳しい  3問        [ 54 ]    › │
├─────────────────────────────────────────────────────┤
│ 10/5 09:12  [全問] 普通  8問          [採点中]  › │
├─────────────────────────────────────────────────────┤
│ 10/3 22:40  [全問] 優しい  8問        [失敗]    › │
└─────────────────────────────────────────────────────┘
```

- 新しい順に20件ずつ表示する
- 採点が終わっていない挑戦は、点数の代わりに状態バッジを表示する
- 0件のときは空の状態(「まだ挑戦していません」+「全問に回答する」)

## 3. 画面遷移

```
ログイン
  └→ カテゴリ一覧
       ├→ カテゴリ作成 ──→ カテゴリ詳細
       └→ カテゴリ詳細
            ├→ カテゴリ編集 ──→ カテゴリ詳細
            ├→ セクション作成 ──→ セクション詳細
            └→ セクション詳細
                 ├→ セクション編集 ──→ セクション詳細
                 ├→ 問題作成 ──→ セクション詳細
                 ├→ 問題詳細 ──→ 問題編集 ──→ 問題詳細
                 ├→ 回答フォーム ──(送信)──→ 結果(採点中 → 完了 / 失敗)
                 │                                ├→ もう一度挑戦 → 回答フォーム
                 │                                └→ 再採点 → 結果(採点中)
                 └→ 履歴一覧 ──→ 結果(履歴詳細)
```

- 削除したあとは1つ上の階層の画面に戻り、トーストを表示する
  - 問題の削除 → セクション詳細
  - セクションの削除 → カテゴリ詳細
  - カテゴリの削除 → カテゴリ一覧
- サイドバーからは、いつでもカテゴリ詳細・セクション詳細へ移動できる

## 4. 表示する文言

| 場面 | 文言 |
|---|---|
| 作成 / 更新 / 削除の完了 | 「〇〇を作成しました」「〇〇を保存しました」「〇〇を削除しました」 |
| 問題数の上限 | 「1セクションに登録できる問題は10問までです」 |
| 回答の未入力 | 「すべての問題に回答してください」 |
| 下書きの復元 | 「前回の下書きを復元しました」 |
| 採点の失敗 | 「採点できませんでした」 |
| 権限なし・存在しないページ | 「ページが見つかりません」(403 / 404 共通のエラーページ) |

- 「〇〇」には対象の種類(カテゴリ / セクション / 問題)を入れる
- 文末は「〜しました」「〜してください」の丁寧語に統一する。「!」は使わない
